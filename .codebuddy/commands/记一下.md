# 记一下

1. **写流水账** — 只记录做了什么，必须使用*追加*到 `daily/流水账/YYYY-MM-DD.md` 的 `## 今天做了什么` 小节末尾
2. **写校准日志** — 只记录犯什么错，必须*追加*到 `.codebuddy/memory/YYYY-MM-DD.md` 的 `## 校准日志` 小节末尾
3. **如果有 To-Do** — 更新 `docs/00-进度台账.md` 的「后续里程碑」表（追加或更新条目）；里程碑有实质进展时同步「阶段产出对账」表

> 本项目约定：`src/stable` 是冻结契约、`src/core` 是领域内核（不认识外部）、`src/adapters` 是唯一接触外部世界处、`src/state` 是唯一写状态处、`src/ui` 只依赖 state + core/model 类型；
> 落点不确定时，先看顶层 [`docs/11-架构与契约定稿.md`](../../docs/11-架构与契约定稿.md) 的「二、分层与目录」与「三、依赖规则」两节。
