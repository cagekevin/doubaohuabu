## 五、探针（先红后绿 · **运行时** —— 本会话最强的一类）

> ★ **为什么能跑运行时探针**：`createConfigStore(userDataPath, safeStorage)` 是**注入式工厂**
> —— `safeStorage` 是**参数** ⇒ 可在纯 node 里换一个"解密必炸"的实现，**无需 Electron**。

```
🧪 probe ｜ TD-13-16 密钥解密失败必须抛（运行时）
   注入：} catch (err) { throw new Error(decryptFailMessage('API 密钥', err)); }
      → } catch (_) { return ''; }
   先红：退出码 1（期望 1）· expect-out 命中（RED getApiKey 静默返回: ""）
   ✅ 还原校验通过（sha256 一致）· 后绿：退出码 0（GREEN）· ✅ 探针成立
```

**探针脚本**（临时落 `/tmp/td1316-probe.cjs`，此处留档以便复现）：

```js
const os = require('os'), fs = require('fs'), path = require('path');
const { createConfigStore } = require('<repo>/electron/api/config-store.js');
const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'td1316-'));
const adapter = { id: 'p1', name: 'P1', defaults: { baseUrl: 'https://x', model: 'm' } };

// ① 能加/解密的 safeStorage ⇒ 写入一份带密钥的配置（并自证正常路径读得回原文）
const okStore = createConfigStore(dir, {
  isEncryptionAvailable: () => true,
  encryptString: (s) => Buffer.from('enc:' + s),
  decryptString: (b) => b.toString().replace(/^enc:/, ''),
});
if (!okStore.setApiKey(adapter, 'sk-test-1234').ok) process.exit(9);
if (okStore.getApiKey(adapter) !== 'sk-test-1234') process.exit(9);

// ② 换成"解密必炸"的 safeStorage（模拟 Keychain 不可用 / 密文损坏）
const badStore = createConfigStore(dir, {
  isEncryptionAvailable: () => true,
  encryptString: (s) => Buffer.from(s),
  decryptString: () => { throw new Error('Keychain unavailable'); },
});
try {
  const ret = badStore.getApiKey(adapter);
  console.log('RED getApiKey 静默返回:', JSON.stringify(ret)); process.exit(1);
} catch (e) {
  console.log('GREEN getApiKey 抛出:', e.message);
  console.log('GREEN publicOf.keyHint:', badStore.publicOf(adapter).keyHint);
  process.exit(0);
}
```

**基线输出（未注入）**：
```
GREEN getApiKey 抛出: API 密钥解密失败（safeStorage 不可用或密文损坏）：Keychain unavailable —— 请到「API 服务」重新保存该密钥
GREEN publicOf.keyHint: （密钥解密失败，请重新保存）
```
