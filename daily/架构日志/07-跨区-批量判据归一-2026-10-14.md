# 07-跨区 · 批量「能不能发」判据归一 — 2026-10-14

## 债

`TD-07-18`（症状：`batchSend.canRun` 0 消费者 + 判据被面板内联重写）

## 病因

`canRun`（`state/batchSend.ts:267`）＝「这批 id 里**可发送**的 **≥2 个**」，是 **state 层的判据**；
而 `ui/panels/BatchSendPanel.tsx:88` **内联重写**了同一判据（`targetIds.length < 2`，
因 `targetIds` 已按 `BATCH_SENDABLE_TYPES` 筛过 ⇒ 语义完全等价）。

⇒ 面板**绕过**了 state 的判据（M3：同一真相两份）；而绕过的那份**活了**、真源那份成了"死方法"。

## 归位

| 改 | 内容 |
|---|---|
| `BatchSendPanel.tsx:88` | `if (targetIds.length < 2) return null;` ⇒ **`if (!batch.canRun(targetIds)) return null;`** |
| 同文件 `useMemo` deps | 补 `batch`（判据来源变了，deps 必须跟上） |

★ 归位后：判据**只有一处**（`canRun`），面板不再可能与之漂移 —— **不需要新增守卫**。

- `npm run check` → **6 道全绿（2067 条）**
