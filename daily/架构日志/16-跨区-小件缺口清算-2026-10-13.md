## 一、`TD-16-91` —— 素材节点尺寸（**前提被推翻**）

**债的原话**：「本仓 `addNode` **不接受节点级尺寸** ⇒ 用类型默认尺寸」。

**取证后更正**：
- `addNode` **早已支持** `size?: {w,h}`（`slices/canvas.ts:327-332`，**2026-10-12 就补了**）⇒ 债的前提**已过期**。
- 拖放 / 画廊路径（`materialBatch.ts:148-149` 的 `width: p.w, height: p.h`）**本就传**。
- **取帧路径**（`GenVideoNode.tsx:432`）**本就传**（还带一段注释解释为什么必须传）。
- **唯一漏的** = **截图路径**：`capture.ts:82` → `addScreenshotMaterial` 没传。

**修**：`addScreenshotMaterial` 补 `{w:220, h:180}`（源 `:28343-28344` 的字面量，收进 `core/rules/capture.SCREENSHOT_NODE_SIZE`）；顺手清掉 `canvas.ts` 的过期注释。

## 二、`TD-16-86` —— toast 默认时长

源 `showToast(n, r = 'info', s = **2600**, o = null)`（`shared.js:30542`）；本仓 `TOAST_DURATION_MS = 3000` ⇒ 每条不带时长的 toast 多 400ms。**改 2600**。

> ⚠️ **凭证限制如实说明**：该常量是 `state/slices/ui.ts` 的**模块私有**常量 —— `state` 片不写单测、`ui` 片禁写测试 ⇒ **无机器守卫**（闸盲区）。凭证 = 源出处引用 + 全量门禁绿。

## 三、`TD-16-99` —— 文生图历史版本日期格式（**真缺口，已确证**）

**债的原话**：「源 `ZL.jsx:305` 用全局别名 `S(V.ts)`（不在 import 表）⇒ 未核对」。

**取证后确证**：`S` **不是全局别名** —— 它是 **`ZL.jsx:89-98` 的本地函数**（抽取器把局部标识符一股脑列进「TODO(全局, 无需 import)」catch-all ⇒ 那是**抽取器的盲区**，不是源的写法）：

```js
const S = V => { const pe = new Date(V);
  return `${pad(pe.getMonth()+1)}-${pad(pe.getDate())} ${pad(pe.getHours())}:${pad(pe.getMinutes())}`; };
```

⇒ **`MM-DD HH:mm`，不带年份** —— 与**文生视频历史**（`YL.jsx:460-470` 的 `te`）**同形**。

**本仓**：`GenImageNode.tsx:313` 用了 `formatDateTimeMinute`（`YYYY-MM-DD HH:mm`，**带年**）⇒ **渲染与源不一致**。**改 `formatMonthDayMinute`**（`lib/time.ts:133`，`VideoNode`/`GenVideoNode` 同款）。

## 四、`TD-16-121` —— `saveTextFile`（**判不落**）

源 `saveFile` / `save-file` **全目录 grep 为空**（**源自己也没有调用方**）；本仓「导出工程」按钮已按源删除（`TopBar.tsx:9` 明记）⇒ `hostOps.saveTextFile` 无生产消费者属**正确形态**（同 `jobCancel` / `runScript` 先例）。已把 `hostOps.ts` 表格里过期的「消费者 = `TopBar`（导出工程 JSON）」改为「保留能力位」。

**零炸三问**：
1. **哪些行为被改了？** ① 截图素材节点由「类型默认框」变 **220×180**（源行为）；② 文生图历史版本日期由带年变**不带年**（源行为）；③ 默认 toast 由 3000 变 **2600ms**（源行为）。
2. **改前能走的仍能走？** 全量 2051 条测试全绿；`addScreenshotMaterial` 只**多**传一个 size（`addNode` 本就吃它）；`formatMonthDayMinute` 是既有实现（三处同款）。
3. **改前会失败的仍失败？** 是 —— `addScreenshotMaterial` 的守卫（`!dataUrl` / 找不到源视频 ⇒ `null`）未动。
