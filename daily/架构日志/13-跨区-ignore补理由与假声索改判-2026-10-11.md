## 一、`TD-13-17` 施工（7 处补理由 · **注释-only**）

债点名的 2 处 + **判据适用面**扫出的同族 5 处，共 **7 处** `catch { /* ignore */ }` 补上**真理由**：

| 处 | 采集的是什么 | 补的理由（要旨）|
|---|---|---|
| `:126` | macOS **辅键**（平台 UUID）| 只影响指纹稳定性（机器码由 primary/secondary/fallback 组合，少一档仍出码）|
| `:144` | Windows **主键**（BIOS 序列号）| 同上（wmic 不在 / 无权限）|
| `:152` | Windows **辅键**（主板 UUID）| 同上 |
| `:161` | Linux **主键**（`machine-id`）| 同上（文件不存在 / 无权限）|
| `:170` | Linux **辅键**（DMI `product_uuid`）| 同上 |
| `:181` | **兜底档**（CPU 型号）| 指纹仍可由 primary/secondary 组合 |
| `:393` | `req.destroy()`（收尾）| **已在**错误/超时路径上收尾 ⇒ destroy 失败无副作用 |

★ **为什么 `/* ignore */` 不算理由**：它只说"我不在乎"，没说**为什么不在乎** ⇒ 读者无法判断这是
"刻意的良性忽略"还是"忘了处理"（这正是 `TD-16-37` 想消灭的形态）。

**复核**：`license.js` 的「无理由 ignore」= **0** ✓（残留的 1 处 grep 命中是**本注释里的引文**）。
`node --check` ✅ · `npm run check` ✅ **1387 passed（5 道闸）**。
