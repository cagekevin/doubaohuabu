# 04-跨区 · 批量取图补整体超时兜底 — 2026-10-13

## 债

`TD-04-13`（真 bug · 扫描链静默挂起）

## 源 vs 本仓

源 `vP`（`shared.js:33675-33768`）**末尾**有一条整体超时：

```js
setTimeout(() => f({ timeout: true }), mP);   // mP = 150000（:33652）
```

本仓 `adapters/host/electron/index.ts` 的 `fetchImages`：Promise **只靠 `onLovartFetchDone` 收尾** ——
事件**永不达**时（后端异常 / 进程挂）⇒ **永不 resolve** ⇒ `materializeScan` 一直 await
⇒ **扫描链静默挂起**（用户点了扫描，转圈不结束，没有任何提示）。

## 落点

| 文件 | 改 |
|---|---|
| `constants/index.ts` | 新增 `FETCH_IMAGES_TIMEOUT_MS = 150000`（逐字对源 `mP`） |
| `constants/text.ts` | `COMMON_TEXT.fetchImagesTimeout`（源超时**无文案** —— 它只回 `{timeout:true}`；本仓 `Result` 需要 message ⇒ 立唯一真源） |
| `adapters/host/electron/index.ts` | `fetchImages` 加 `timer`（`finish` 里 `clearTimeout`，防悬着）＋ `setTimeout` 收尾为 **`err('page-timeout', …)`** |

★ 超时按**如实失败**（**不**返回半份"成功"）：调用方 `materializeScan` 对 `!r.ok` **逐张计失败**（不静默）⇒ 用户看到「抓取失败」而不是永远转圈。
