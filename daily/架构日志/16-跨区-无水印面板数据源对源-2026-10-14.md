# 16 跨区 · 无水印面板「数据源对源」（图+视频）（2026-10-14）

## 用户可见的问题

「**无水印资源**」面板**从不显示图**（只显示视频），计数也只写「视频 N」。

## 病因：**数据源读错了**（不是缺实现）

| | 源 | 本仓（改前） |
|---|---|---|
| 面板条目 | **瞬态 CDP 捕获列表** `ce`（`_Component43.jsx:128`；每次推送 `oe(ve.items)` 整体替换），**图 + 视频** | `videoShares`（**只视频**） |
| 计数徽标 | `ce.length`（`BackendView:270` 注释自己就写着「原 `ce.length`」） | `videoShares.length` |
| `videoShares` 的真用途 | **检测播种**（`_Component43.jsx:531`）——**从不显示** | 被当成面板数据源 |

⇒ 三处注释还把这个缺口归因于「`onDolaMedia` 未落」——**实况是早已落**。

## 归位

1. `state/slices/ui.ts`：新增**瞬态** `dolaMediaItems` + `setDolaMediaItems`（内存态，源即组件局部 state）。
2. `state/dolaMedia.ts`：`handle` 里 `setDolaMediaItems(event.items)`（对齐 `oe(ve.items)`）。
3. `ui/panels/WatermarkPanel.tsx`：改读 `dolaMediaItems`；图 → `<img>`、视频 → `<video>`；计数 `count(图, 视频)`。
4. `ui/panels/BackendView.tsx`：徽标 ⇒ `dolaMediaItems.length`。
5. `constants/sendPanelText.ts`：`count` 改回「图 N · 视频 M」+ 加 `typeImage`。
6. 清掉因此悬空的 CSS（`.noPoster` / `.account` / `.removeBtn`）。
7. `videoShares` **保留**（检测播种的真实消费者）。

真源回写：`docs/DATAFLOW.md` §十九（面板数据源段）。
