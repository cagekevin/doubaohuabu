### ★★ 本轮查证时发现：`dead-code` 闸**当前被关掉了**

`npm run check` 报「✅ 全部通过（5 道）」，但**单独跑** `node scripts/check-dead-code.mjs` 仍报 3 条。
根因在 `scripts/gates.manifest.json`（**工作区未提交改动**）：

```json
"disabled": ["dead-code"]
```

⇒ `npm run check` 会打印 `⭕ 持久关闭（manifest.disabled）：dead-code` 后**跳过它**。
**这是「门禁假绿」**：`npm run check` 的绿**不代表**死代码闸绿。
⚠️ **本文件不擅自开关它**（那是刻意的动作，且重开会让 `check` 因那 3 条非本轮的项变红）
—— **留给用户裁**：① 保持关闭（则「永不复涨」失效）② 重开并先清那 3 条。

## 八、探债（本轮的债明细真源）

### TD-16-86 · `pushToast` 默认时长与源版不一致 —— **[待还]**

- **现象**：源 `showToast(n, r='info', s=2600)` 的默认是 **2600ms**；本仓 `state/slices/ui.ts` 的
  `TOAST_DURATION_MS = 3000` ⇒ **每一条不带时长的 toast 都比源版多显示 400ms**。
- **影响**：`ApiSettings` 的「配置已保存」等提示（源版也未传时长）会跟着偏。
- **本轮为什么不动它**：改它会**同时改变全应用所有 toast 的时长**（用户可感知），
  且与「API 面板」不是同一件事 ⇒ 零炸（不顺手改）。
