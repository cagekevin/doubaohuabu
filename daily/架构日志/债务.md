# 架构日志 · 技术债索引（轻量登记簿）

> **定位**：豆包画布/app 全仓库技术债的**轻量索引**（一行一债、摘要一句话，不存叙述）。明细真源 = 各区域架构日志
> `daily/架构日志/<NN>-<区域>-<日期>.md` 的「探债」段（本表末列锚点指向它）。
> 区域清单（编号 / 区域名 / 层）唯一人工维护点 = `scripts/arch-index.mjs` 的 `AREAS`。
>
> **读写唯一入口 = `scripts/debt.mjs`（禁手写本表、禁 ReadFile 全量本文件）**：
> - 读：`node scripts/debt.mjs list [--area 07] [--status 待还] [--all]` · `node scripts/debt.mjs show TD-07-1`
> - 写：`node scripts/debt.mjs add --area 07 --summary "…" [--class 增债] [--rate 中] [--anchor <区域文件>]`
>         `node scripts/debt.mjs resolve TD-07-1 --note "…"`（**就地改状态，不新增行**）
> - 体检：`node scripts/debt.mjs audit`（只读报告，不是闸）
>
> **列规范**：归类 ∈ `还债/持平/增债` · 利息率 ∈ `高/中/低` · 状态 ∈ `[待还]`/`[待用户拍板]`/`[已解决 <日期>]`/`[已裁定非债 <日期>]`；
> 摘要 ≤1 行、**禁出现竖线 `|`**（用 `／`；裸 `|` 会撑破表格列）。
> **ID 规则**：`TD-<NN>-<n>`，永久绑定首次发现的区域；跨区引用只写 `@见 TD-xx`，不搬运明细。
> **PS 注意**：PowerShell 传参会截断 ASCII 双引号，`--summary` / `--note` 正文请用中文引号 `「」`。
> **历史**：本项目自 2026-10-10 起启用本账本（从 maomao 移植 `debt.mjs` + 本表），此前无债账。
