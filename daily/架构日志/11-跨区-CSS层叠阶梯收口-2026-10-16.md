# 11-跨区 · CSS 层叠阶梯收口：归一入层 — 2026-10-16

## 判据

> 浏览器归一（`reset.css`）与真源（`.btn` 一族）**同住 `@layer base`**，层内靠**特异性**分胜负
> （`button` 0,0,1 < `.btn` 0,1,0）⇒ 真源赢，而归一仍兜住**没被真源接管**的元素。
>
> ★ 选「同层」而不是「再开一层 `reset`」的唯一理由：**层序与文件加载顺序无关**。
> 多开一层就得靠"谁先被加载"决定胜负 —— 而 `css -- export` 按文件拼 `ui-real.css`，
> 层序会翻（归一反过来压真源）。同层没有这个失败面。
>
> 口径落在 `docs/CSS规范.md` §1.4（唯一载体）＋ `docs/判据登记表.md` 同日新增一行。

## 病因

`reset.css` **未分层** ⇒ 按「未分层 > 分层」压过 `@layer base` 的真源
⇒ 真机所有 `.btn*` 的 `background` / `border` / `padding` / `font-size` / `color` **被静默抹掉**
（症状：主按钮变全透明深字）。

## 本轮处置

1. `src/styles/reset.css`：整份入 `@layer base`（它的选择器**全是裸元素**，特异性天然低于真源的类）。
2. `docs/CSS规范.md`：新增 **§1.4 层叠阶梯**（唯一载体）；§2 口径段改为指针，**不复述**。
3. **删** `docs/mockup/assets/{mockup,activate,start,backend}.css` 里 4 份 `revert-layer` 补丁
   与其「这一行要回套真机」说明 —— 根因修好后，**补丁与它的指令都成了错的**
   （照它抄进真机就违反 §1.4；同一真相的第二份 ⇒ 删）。

## 凭证（先红后绿）

- **绿**（现状）：`.btn.btnGhost` 计算样式 = `border:1px solid` · `padding:8px` · `color:rgb(75,85,99)`（真源 `.btnGhost` 前景）
- **红**（负例探针：把归一改回**未分层**后注入）同一条 = `border:0px` · `padding:0px` · `color:inherit`
  ⇒ 修的是**机制**，不是巧合。
- **构建产物**：`dist/assets/index-*.css` 全文**只有一个** `@layer base{`；reset 在前、真源 `_btn_*` 在后（同层）。
- `npm run typecheck` · `npm run lint` · `npm run lint:dead-code` 全绿；`npm run test:affected` ⇒ 无测试射程（CSS / 文档面）。
