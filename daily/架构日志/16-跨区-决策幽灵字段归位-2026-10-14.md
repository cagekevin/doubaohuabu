# 16-跨区 · `ApiJobDecision.jobId/job` 归位 — 2026-10-14

## 债

`TD-16-135`（幽灵字段 M6）

## 追因

落点 `state/subscriptions` **不读** `decision.jobId` / `decision.job`（grep 零命中）——
任务快照回灌早已由落点**直接用事件本身**完成：`upsertApiJob(job)`，且发生在**调 `applyApiJobEvent` 之前**。

⇒ 决策把这两个字段带回来纯属**越权预写**：把源版「第一件事 `apiJobs[jobId] = n`」（源里是**直接写 store**）
照搬进了决策产物，而本仓那件事已归落点。

## 归位

| 改 | 内容 |
|---|---|
| `core/usecases/applyApiJobEvent.ts` | 删 `ApiJobDecision.jobId` / `job`（声明 + 构造 `{ library: [] }`） |
| `core/usecases/tests/applyApiJobEvent.test.ts` | 删两条**验实现**的断言（`d?.jobId` / `d?.job`）；两个测试名改为当下口径（「带上任务快照」→「空壳决策」·「只记快照」→「无落点动作」） |

## 凭证

- `npx tsc --noEmit` → 0（改后暴露并清掉了测试里两处引用）
- `npm run check` → **6 道全绿（2067 条）**
