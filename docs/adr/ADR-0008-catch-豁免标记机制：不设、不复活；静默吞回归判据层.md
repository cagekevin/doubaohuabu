# ADR-0008 · catch 豁免标记机制：不设、不复活；静默吞回归判据层

- **状态**：生效
- **结论**：禁复活「标个理由就放行」的机器机制（自造插件／check:catch／登记表）；静默吞由 no-empty ＋ 失败透传守。// catch-ok: 是**人工留痕约定**（无机器校验），存量只降不升。
- **日期**：2026-10-16
- **裁定人**：用户
- **触发**：系统性搬运ADR-0008（本仓 1 处引用；本仓 2026-10-13 已自行删过该机制）

## 背景

**本仓自己踩过这个坑**：该机制曾于 **2026-10-11** 建过（自造内联插件 `local/no-silent-catch` ＋ `check:catch` 脚本），**2026-10-13 整体删除**。删的判据（逐字来自当时的实测）：

1. 它**唯一**的出口是**写一句自由文本**理由，而闸**自认**「只保证标了、不保证理由对」⇒ 合法通过成本 ≈ 0；
2. `.catch(回调)` 分支只要给回调**加个没人用的形参**即过（`if (cb.params.length > 0) return;`）⇒ 一行破；
3. 更早的 grep 版还逼出**绕行写法** —— 有文件为躲逐行正则把 `catch (_) {` 与 `}` **拆两行**，注释里写明「为规避闸」；
4. 它被当**免检章**（`state/sendQueue.ts` 的注释写着「下轮不要再把它当待留痕重开」）。

**当前状态（实测）**：catch 守卫的载体 = `eslint.config.js` 的 `no-empty` **一份**（默认即 `allowEmptyCatch:false`，零维护、**无逃逸口**）；`// catch-ok:` = **人工留痕约定**，全仓 **14 处 / 7 文件**，**零机器校验**。

## 判据（它凭什么成立 / 为什么不成立）

- **只判"标记存在性"的闸 = 假绿**：合法通过成本 ≤ 绕行成本 ⇒ **闸在生产它本要禁止的行为**（成本守恒律）。
- **理由不可机器核验** ⇒ 不许作**豁免通道**（"贴一句话即合法"把「处理错误」降级成「写一句话」）。
- **修法只有一条**：**去处理它** —— 失败由产生它的那层以判别联合透传（见 `ADR-0005`），消费者只转发。
- **`no-empty` 是最强载体**：零维护、无逃逸口、编译器级，正是 `ADR-0002` 六级落点里"删/类型/唯一入口"优先于"机器闸"的位置（**不该**再叠一道自造闸）。

## 决议

1. **禁复活三件**：自造 eslint 插件（如 `no-silent-catch`）· `check:catch` 类 npm script ／ 闸 · `catchOk` 类**理由码登记表**（"标个码就合法"的出口）。
2. **`// catch-ok:` 的定性**：**注释性留痕约定**，无任何机器校验 —— 写前**必须回读被 catch 的代码**；**同一"吞"语义在 ≥3 处手写 ⇒ 收口成原语**（自带理由 ＋ 测试 ＋ 唯一实现），禁止到处复制标记。
3. **存量口径：只降不升**。基线 = **14 处**（可复算：`git grep -c "// catch-ok:" -- src electron`）；新增即违规，须在本轮说明"为什么这处必须吞 + 为什么不能改结构"。
4. **预期内失败**：一律 `logger.warn` ／ 透传判别联合；**真空 catch** 由 `no-empty` 拦（不许用标记绕）。

**边界（对方未搬 ⇒ 保留仓外指针，禁省略）**：`母仓 ADR-0016`（闸不许凌驾正确性 · 成本守恒律 —— 本仓等价载体 = `scripts/gates.manifest.json` 的 `_design.gateCost`）· `母仓 ADR-0002`（已搬入 `ADR-0005`：压平必须留痕）。与 `ADR-0003` 的关系：**删**这套机制时按它的四关走（**能力关**答案 = "用户能做的事没少" —— 删的是闸，不是用户能力）。

**落点**：`eslint.config.js`（TS 块 ＋ electron 块的 `no-empty`，两处）· `.codebuddy/commands/架构师改码7步法.md` Step 4 红线③（结构性空 catch 的处置）· `docs/过渡资料/16-缺口落点与写法定稿.md` 的 2026-10-13 轮（**过程留痕，不回改**）。

## 后果

- ✅ **收益**：删掉一道"一句话即可绕过"的假护栏；静默吞从"贴标签合法"退回"改结构"；判据有了本仓主场（此前只在 eslint 注释 ＋ 步骤文档 ＋ 轮次记录里）。
- ⚠️ **代价 / 回潮风险**：**禁静默吞退回只写在判据与注释层（无机器守卫）** ⇒ 回潮成本低。若将来要重建守卫，**必须先过"建闸前置评审"**，且**不能用自由文本标记作豁免通道**。
- 📌 **违反时的判据（可机判）**：
  1. `git grep -nE "no-silent-catch|check:catch|catchOk"` 命中 ⇒ **复活 ⇒ 违规**（注释里的历史叙述除外）；
  2. `git grep -c "// catch-ok:" -- src electron` **> 14** ⇒ 违规；
  3. `// catch-ok:` 贴在**非空 catch** 上 ⇒ 违规（历史实测过 7 处这种形态）；
  4. 同一"吞"语义在 ≥3 处手写、未收口为原语 ⇒ 违规。
  ⚠️ **诚实边界**：①②可机判；③④须人工核对（"同一语义"机器判不了 —— `ADR-0002` 第 6 级）。
