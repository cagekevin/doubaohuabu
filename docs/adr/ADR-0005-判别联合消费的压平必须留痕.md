# ADR-0005 · 判别联合消费的压平必须留痕

- **状态**：生效
- **结论**：判别联合消费走唯一出口（压平即留痕）；裸 `r.ok ? v : x` 丢掉 err ＝ 静默吞。**例外**：探测语义站点（坏输入与「不是」对调用方同答案）不套原语，判非债。
- **日期**：2026-10-16
- **裁定人**：架构师（取证后自定）
- **触发**：系统性搬运ADR-0005（本仓 3 处引用指向它；执行面 = `core/model/result.ts`）

## 背景

本仓 **3 处**引用这个编号（`架构师写新业务代码.md` 的契约表与失败判据交叉校验清单），本体在仓外。本仓的执行面已经存在：

- `src/core/model/result.ts` 的 `UsecaseResult<T>` = `{ ok: true; value } | { ok: false; reason; message }`（判别联合本身）；
- `src/core/rules/failure.ts` 的 14 类分类表（`reason` 的取值域）。

**被推翻的旧形态**：**半截收口**——判别联合消除了"不可区分"，却**没有消除"静默"**：消费者 `r.ok ? r.value : <空值>` 一压，原始的 `reason` / `message` 就蒸发了 ⇒ 用户看不到原因，排查也没有线索。

## 判据（它凭什么成立 / 为什么不成立）

- **压平丢 err ＝ 静默吞**：`{ok:false}` 携带的是**生产者给的完整失败信息**；压平时丢弃 = 消费者越权（生产者给全 / 消费者只转发）。
- **但"压平必留痕"不是对所有站点成立**（非同质）：**探测语义**站点（"这段文本是不是画布 JSON"）里，坏输入与"不是"对调用方**答案相同** ⇒ 留痕只会把正常路径刷成噪音 ⇒ **判非债**。
- **边界（重要）**：**logger 之下的层没有这条义务** —— 它们连 import 留痕都不可能（会成环）。本仓**当前无此层**（全仓仅 2 处 `import { log }`：`core/usecases/scanGallery.ts`、`lib/phash.ts`）⇒ 该情形**无对象**，不为此造判据（见边界段）。

## 决议

1. **压平必须携带可展示信息**：失败分支不得退化成 `null` / `''` / `[]` / `{}` —— 至少保留 `reason`（分类）与 `message`（可展示文案）。
2. **唯一出口**：同一「压平」语义在有 ≥2 处手写时，**收口成 1 个原语**（自带理由 + 唯一实现）；**禁**各处各写一处裸三元。
3. **生产者给全 / 消费者只转发**：文案由**产生失败的那层**给，消费者**零自造文案**（也不得把失败重分类成"环境问题"）。
4. **探测语义站点显式豁免**：判非债，但**须就地写明"此处是探测语义"**（否则下一个人会当违规登记）。
5. **不加机器闸**：违反判据（`r.ok ?` 形态）**不可机器判定**（形态命中 ≠ 违规，探测语义站点合法）⇒ 按 `ADR-0002` 第 6 级：写明"不能"，靠 review + 人读。

**边界（对方未搬 ⇒ 保留仓外指针，禁省略）**：`母仓 ADR-0003`（logger 之下失败只能由返回值表达 —— **本仓当前无对象**，将来若出现 logger 之下必须靠返回值表达失败的层，按它办）· `ADR-0006`（兜底六形态，已搬入 `ADR-0006`：那条管"**不许把失败表达成没事**"，本条管"**失败怎么表达**"）。

**落点**：`src/core/model/result.ts`（契约形状 = 唯一真源）· `src/core/rules/failure.ts`（14 类分类表）· `.codebuddy/commands/架构师写新业务代码.md` 的契约表与 Step 4（指针）。

## 后果

- ✅ **收益**：判别联合从"消除了不可区分"推进到"**消除了静默**"；消费者不再有第二份文案；3 处指针收敛为 1 处。
- ⚠️ **代价 / 回潮风险**：`tryParse` 类原语仍可被直接消费 ⇒ 裸三元会回潮；且**没有机器闸**兜底 ⇒ 防的是 review。
- ⚠️ **反滥用**：不许拿"探测语义"当**通用豁免口**（它是判据，不是挡箭牌：写"探测"必须能指出**坏输入与不是对调用方同答案**）。
- 📌 **违反时的判据**：
  1. 全仓出现 `r.ok ? … : …`（或 `re.ok &&`）且失败分支**无** `reason` / `message` 传递 ⇒ 违规（探测语义站点除外，须已声明）；
  2. 失败文案由**消费者**就地自造（生产者已给 `message` 却不用）⇒ 违规；
  3. 同一「压平」语义在 ≥2 处**手写**、未收口为唯一原语 ⇒ 违规；
  4. 新写"探测语义"豁免却答不出"对调用方同答案"⇒ 违规。
  ⚠️ **诚实边界**：上列**均不可机器判定**（形态扫描会误伤探测语义站点）⇒ 按 `ADR-0002` 第 6 级给人工判据，**禁硬凑 grep**。
