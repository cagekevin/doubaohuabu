# ADR-0013 · 测试只锁用户可感知契约（禁文档测试与存在性断言）

- **状态**：生效
- **结论**：测试只锁用户能感知的契约（能做的事不变）；禁文档测试（文档写错就改文档，不靠断言守）、禁源码文本断言与存在性测试（自证式：改个空格就红、逻辑坏了却绿）。
- **日期**：2026-10-16
- **裁定人**：用户
- **触发**：系统性搬运ADR-0013（本仓 2 处引用）

## 背景

本仓 **2 处**引用它，且都带着一条**实证**：`ADR守护者.md`「想加检查 ⇒ 先问「它判的是文档还是用户可感知契约」—— 判文档的一律**不加**（用户裁定『**文档不需要任何测试**』）；原 `check-doc-refs` 已因此于 **2026-09-20** 删除）」· `架构师改码7步法.md`（同裁定：原 `scripts/check-doc-refs.mjs` 验证债号真伪，已删，改由 `debt.mjs show` 逐条取证、**不靠闸**）。

本仓 **已有半条**（`AGENTS.md` §六 测试边界）：只测纯逻辑 · 不测 `adapters/**`、`ui/**` 不写组件测试（**假守卫**）· 断言红线「**实现一变必红**；自证式断言（仅验不崩 / mock 被调用）**无效**」· UI 走 `scripts/verify-*.cjs`。⇒ 缺的是**统一判据**（凭什么判一个测试合法），以及**为什么**（此前的形态）。

**被推翻的旧形态**：用测试去**锁文档/文字/存在性** —— 它**不锁用户能做的事**，只锁"我写了这行字"：

| 形态 | 坏在哪 |
| --- | --- |
| 文档测试（扫 md 里的编号/链接） | 文档写错**改文档**就行；用断言守 ⇒ 文档一改就红，红的是测试不是错 |
| 源码文本断言（`toContain('xxx')`） | 改个空格就红、逻辑坏了却绿 ⇒ **负例探针不成立** |
| 存在性测试（组件/文件存在） | 仅验"不崩"⇒ 与 `ADR-0002` 第 5 级"负例探针证它会红"直接冲突 |

## 判据（它凭什么成立 / 为什么不成立）

1. **合法性 = 它锁的必须是"用户能感知的契约"**（能做的事不变）；锁不到 ⇒ 它没有防线作用，只有维护成本。
2. **断言红线的可判形态**：**改个空格就红 ＋ 逻辑坏了却绿** ⇒ 自证式 ⇒ 无效（正例：改坏实现必红）。
3. **文档的守门人是人不是断言**：文档写错就改文档（本仓已删 `check-doc-refs` 为实证）；ADR 体系自身的完整性走 `node scripts/adr.mjs audit` / `refs --check`（**维护 CLI，不是闸**）。
4. **边界（重要，防一刀切）**：**跨文件规范扫描闸不属此形态** —— 它扫全仓查"是否遵守某条不变量"，**注入违规会红** ⇒ 合法（其合法性按 `ADR-0002` 第 5 级 M2：**必须有负例探针**证明它会红）。**不许据本条把它当自证式删掉**。

## 决议

**① 三档合法测试**

| 档 | 对象 | 形态 |
| --- | --- | --- |
| 纯逻辑单测 | `core/rules` · `core/usecases`（注入 mock）· `stable/migrations` · state 纯 reducer | Vitest（node），位置 `src/**/tests/**/*.test.ts` |
| 数据等价 | 迁移 / 快照 | 输入→输出逐字对照（`JSON.parse(JSON.stringify(...))` 造快照**合法**，见 `ADR-0007`） |
| UI 端到端冒烟 | `ui/**` · `adapters/**` | `scripts/verify-*.cjs`（**先 `npx vite build`**），不进 vitest |

**② 三类禁止**：判**文档**的测试 · **源码文本**断言（`toContain('我写的那行')`）· **存在性**测试（只验"不崩 / mock 被调用"）。

**③ 失败归因顺序**：测试失败 ⇒ **先判"是不是我错了"**（同批过正确性 / 职责边界 / SSOT 三关）⇒ 确认被测实现无误、断言过时，才同步补测；**禁止静默改断言把红改绿**。

**④ 如实登记的盲区（诚实声明，不是缺口清单）**：`state/**` 可藏测试（本仓原则 7 只拦 `ui`/`adapters`）· depcruise 拦不到**类型重复** · 已弃的 grep 型不变量（色值 / 端口纯净 / `.catch` 形态）**现无机器守卫**。

**边界（对方未搬 ⇒ 保留仓外指针，禁省略）**：`母仓 ADR-0041`（M2–M6：闸绿不算证据 / 负例探针 —— 已在本仓 `ADR-0002` 第 5 级引其口径，原条**未搬**）。与 `ADR-0002` 的分工：那条给"判据该落在哪一级"，本条给"**测试这种载体什么时候合法**"；与 `ADR-0008` 的分工：那条管 catch 守卫（`no-empty` 是唯一载体）。

**落点**：`AGENTS.md` §六（测试边界）· `.codebuddy/commands/测试门禁5步法.md`（L0–L3 分级）· `scripts/verify-*.cjs`（UI 冒烟）· `vite.config.ts`（`test.isolate` 与模块级可变状态清理）。

## 后果

- ✅ **收益**：新测试有统一合法性判据（用户能做的事锁住了吗）；"为文档加测试"的念头被明确关掉（有实证）；2 处仓外指针收敛为 1。
- ⚠️ **代价 / 回潮风险**：**"不崩"式测试最省事** ⇒ 会被当"有测试了"；且本条**无机器守卫**（"是否锁住可感知契约"须人判）⇒ 靠 review 与负例探针。
- 📌 **违反时的判据**：
  1. 新增测试**只验**"不崩 / mock 被调用 / 文件存在" ⇒ 违规（自证式）；
  2. 为让测试通过而**改断言**（而不是改逻辑）⇒ 违规；
  3. 新增**判文档**的测试（扫 md 编号 / 链接 / 字面量）⇒ 违规（`check-doc-refs` 已删的同一理由）；
  4. 据本条删掉**跨文件规范扫描闸** ⇒ 违规（反滥用：它注入违规**会红**，属合法形态）；
  5. 断言过时却**没有**先判"是不是我错了"就补测 ⇒ 违规。
  ⚠️ **诚实边界**：1、2、5 不可机器判定（须人读）；3 可半判（测试文件里扫 `*.md` / `readFileSync`）；4 需回读证据。
