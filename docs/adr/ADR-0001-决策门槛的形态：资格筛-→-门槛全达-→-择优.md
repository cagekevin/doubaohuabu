# ADR-0001 · 决策门槛的形态：资格筛 → 门槛全达 → 择优

- **状态**：生效
- **结论**：决策按三关判：资格筛（红线／「既有约定」—— **判据本体见 `ADR-0004`**）→ 门槛全达（正确性／职责边界／SSOT 任一不过＝停）→ 择优（复杂度须量化）；留痕只在两个观察点（拍板时每选项各带／落账入轮次 §九）。
- **日期**：2026-10-16
- **裁定人**：用户
- **触发**：系统性搬运ADR-0001（本仓 8 处引用指向它，判据本体在仓外）

## 背景

本仓 `.codebuddy/commands/` 里 **8 处**写「三关内容 / 留痕格式 / 违反判据只在 `母仓 ADR-0050` 一处，本文件不复述」⇒ AI 读到的全是**指针**，指针的目标不在本仓（`refs --check` 因 `母仓 ` 前缀豁免 ⇒ 不报断链，但也没人读得到）。

**被推翻的旧形态**：把判据冲突写成**一条线性序（高者胜）**，并被复制到多处 —— 它让**越权**可以被「正确性更高 / 复杂度更低」买走。

## 判据（它凭什么成立 / 为什么不成立）

- **线性序与停手规则冲突 ⇒ 不成立**：`架构师改码7步法.md` 底线②明写「**越权就是结构错误，不是风格问题 → 停**」——越权不该被更高层买走 ⇒ 它不是排序里的一格。
- **「既有约定」不构成判据**：引用前先答「它凭什么成立」，答不出就是待消灭的对象 ⇒ 只能当**资格筛**，不能占排序一格。
- **仓内判据本就是合取**：`AGENTS.md` §五「载体数 = 1」（SSOT）与效力排序是**并列成立**，不是二选一。
- **只有子集可机判**：可机判 = 三关的**副本数**与**落账凭证**；「该由哪层做 / 复杂度降了没」须人判（ADR-0002 第 6 级：写明"不能"）。

## 决议

**① 三关形态（本条为唯一真源）**

| 关 | 内容 | 规则 |
| --- | --- | --- |
| **第 0 关 · 资格筛** | 物理红线（`AGENTS.md` §九 禁区 · `docs/架构与契约定稿.md` §三/§六/§六·五）；「既有约定」的**判据本体见 `ADR-0004`**（本条不复制它的定义） | 答不出 ⇒ **出局**，不参与排序 |
| **第 1 关 · 硬门槛** | ① 正确性（含「**用户能做的事不变少**」）② 职责边界（谁拥有真相谁写；生产者给全 / 消费者只转发）③ SSOT（一份真相、无第二同步点） | **全达才谈下一步；任一不过 ⇒ 停，不许被收益买** |
| **第 2 关 · 择优** | 复杂度（须给改前 / 改后**同一项**量化）＞ 工期 ＞ 兼容性 | 仅门槛全过后才允许此消彼长 |

- **复杂度必须带口径**：给不出"改前 / 改后同一项"的对比 ⇒ 该关视为**未举证**（不是"降了"）。

**② 留痕只在两个"有观察点"的时机**

| 时机 | 谁观察 | 要求 |
| --- | --- | --- |
| **请用户拍板时** | 用户本人（看不到留痕就驳回） | 每个选项**各带一份留痕**：`正确性`｜`职责边界`｜`复杂度`｜`SSOT` 各一行 + 证据。（**选项本身的合法性另判** —— 见 `ADR-0010`，本仓待搬） |
| **本轮落账时** | 轮次文件 + 可复现命令 | 在 `daily/架构日志/<NN>-*.md` 的 **§九 决策留痕**（骨架真源 = `daily/架构日志/_template.md` 该节）补上本轮**有取舍的决定** |

- 只填词（"复杂度降低"而无口径）**不算**留痕；**缺留痕 ⇒ 不许动手 / 不许问**。
- **不挂「AI 内部每个决定」**：没有观察点、不可判 ⇒ 假判据。纯结构动作（改名 / 补类型）在 §九 写一行「无取舍」即可。
- **副本收敛**：三关的**判据语句**只许住本条；`.codebuddy/commands/` 三处只写「插入位置 + 指针」。

**③ 落点**：本条 = 判据本体 · `daily/架构日志/_template.md` §九 = 留痕载体 · `.codebuddy/commands/{架构师改码7步法,ADR守护者,架构师心法}.md` = 指针。

**④ 边界（对方未搬 ⇒ 保留仓外指针，禁省略）**：`ADR-0010`（选项形态：结论＋代价 / 代价等价的真备选）—— 正交：本条管「**该不该交用户 ＋ 每个选项的留痕**」，它管「交出去的东西是**选择还是伪装**」；顺序 = 先按它判形态，再按本条配留痕。`ADR-0004`（既有约定不是判据来源）—— 它是本条第 0 关的依据原文。

## 后果

- ✅ **收益**：越权 / SSOT 缺口不再能被"正确性更高 / 复杂度更低"买走；判据本体回到本仓（8 处指针收敛为指针 1 处）。
- ⚠️ **代价**：门槛全达更贵（三层都要举证）⇒ 留痕必须轻量（一行 + 证据），否则退化成填词。
- ⚠️ **回潮风险**：把门槛写回「一条多档线」（"反正意思差不多"）；把「门槛全达」读成「顺序比较」；把留痕挂回"每个决定"。
- ⚠️ **反滥用（资格筛）**：第 0 关只筛**手上这个动议**；**不得**把"某个既有约定答不出凭什么成立"扩用成「我看不出理由 ⇒ 不干」的通用挡箭牌 —— 那是偷懒，不是资格筛（与 `ADR-0004` 的反滥用同向）。
- 📌 **违反时的判据**：
  1. 施工理由里出现「虽然越权（或多一个同步点），但正确性更高 / 复杂度更低，所以做」⇒ 违第 1 关；
  2. 落账里有取舍的决定而 **§九 无数据行** ⇒ 违留痕（可机判：`grep -A10 "## 九、决策留痕" daily/架构日志/<本轮>.md | grep -cE "^\| [1-9]"` 应 **≥ 1**）；
  3. 三关的判据语句在**本条之外**出现（扫 `docs` · `.codebuddy` · `AGENTS.md`）⇒ 副本，违 ③；
  4. 拿「既有约定如此」当**排序依据**（而非资格筛）⇒ 违第 0 关。
