# ADR-0011 · 收口的验收口径：载体账 N→M，净减才算过

- **状态**：生效
- **结论**：收口按三动作验收：开工前数载体 N（不许估）→ 建真源后逐个销副本（逐个消费点，不是每类载体）→ 收口后 N→M 且 M<N。只加层、不减副本 ⇒ 不算收口。载体四类：数值／类型／配置／文档。
- **日期**：2026-10-16
- **裁定人**：用户
- **触发**：系统性搬运ADR-0011（本仓 1 处引用；本仓有载体数登记制度与 census-ssot 工具，缺口径）

## 背景

本仓**已有制度与工具，缺的只是"算不算收完"的口径**（实测）：

| 已有的 | 位置 | 它管什么 |
| --- | --- | --- |
| 「载体数 N」登记 | `docs/判据登记表.md` 规则 2（每行三要素：真源 ＋ **载体数 N** ＋ 跨板块副本落点；且「**答不出 N ⇒ 说明你没数过载体，不算登记**」） | **静态**：某条判据现在几份 |
| 数载体的工具 | `scripts/census-ssot.cjs`（Step 0 普查：数"SSOT 第二份"的**份数**） | 提供 N |
| 完成目标（入口） | `AGENTS.md` 母体表：「做 SSOT ⇒ `判据登记表` 那一行的**载体数 = 1**」 | **目标** |

**被推翻的旧形态**：「真源已建立」式验收 —— 它是**声索**，不可证伪。反例（母仓实证）：建了真源，载体数却 **7 → 8**（加类型 ＋ 加配置 − 数值 ×2 = 净 0，还多一层间接）⇒ **以收口的名义做了一次纯复杂度增加**。

## 判据（它凭什么成立 / 为什么不成立）

- **载体数是可数事实**：`grep` 定义点即得出 ⇒ **可证伪**；而"已收口到 X"不可证伪。本条只做一件事：**把验收从声索换成数字**。
- **为什么本仓既有制度挡不住**：登记表的「载体数 N」是**静态登记**（某行现在是几份）；本条管的是**一次收口动作做到什么程度算完**（动态）。建了真源但旧载体没退役 ⇒ 表照样能填 N，动作却是半态。
- **载体不只数值**：类型（字面量联合 / enum）· 配置（配置键）· 文档（注释复述）**都不含数值** ⇒ 只按数值清点会**系统性漏报**。
- **只能部分机判**：「哪些算同一判据」由人判断 ⇒ 第 1 步**没有机器防线**，靠"载体账被强制填写"这个动作本身（`ADR-0002` 第 6 级）。

## 决议

**① 三个强制动作，缺一即判未收口**

| # | 动作 | 判据（怎么算做了） |
| --- | --- | --- |
| **1** | **开工前先数载体 N** | 任务书 / 轮次里有载体账「收口前 **N**」；N 由 `node scripts/census-ssot.cjs` 或 grep 得出，**不许估**；**不可事后补**（改后载体已变形） |
| **2** | **建真源后逐个销副本** | 「逐个」= **每一个消费点**，不是每一类载体 —— 真源立好、两条路径接上、第三条漏了 ⇒ **症状原样保留**。每个旧载体要么**删除**、要么**改为指向真源**；**只改注释不算销** |
| **3** | **收口后净减才算过** | 载体账「**N → M**」且 **M < N**；M ≥ N ⇒ 判未收口。**跨栈 / 跨端**允许先加后减、分轮落地，但**不得声称已完成** |

**② 载体四类**（清点单位 = **判据**，不是数值）：**数值**（常量／字面量）· **类型**（字面量联合／enum）· **配置**（配置键）· **文档**（注释复述）。

**③ 载体清单不写进本条** —— 它会过期、会被抄成第二份（正是本条要禁止的形态）⇒ **每次收口在任务书里现填**。

**边界（对方未搬 ⇒ 保留仓外指针，禁省略）**：`母仓 ADR-0031`（同一判据的域外副本：**探测重复收口 / 判据重复禁合并** —— 收口前先分类，**未搬**）。与 `ADR-0003` 的分工：**那条管"删不删"（准入门）**，本条管"**收口动作做到什么程度算完**"。与 `ADR-0009` 的分工：那条量"模块好坏 / 接口宽度"，本条量"**同一判据的份数**"。

**落点**：`docs/判据登记表.md`（「载体数 N」列 = 账，收口后就地改）· `scripts/census-ssot.cjs`（数 N 的工具）· `AGENTS.md` 母体表（入口指针）。

## 后果

- ✅ **收益**：收口的验收从声索变**可数**；半态当场暴露（**填不出载体账 ⇒ 判未收口**）；本仓"载体数 = 1"这条完成判据从"只有目标"变为"**有动作与口径**"。
- ⚠️ **代价 / 回潮风险**：每次收口多一步清点；**最常见偷懒 = 只清数值层**（类型／配置／文档三层天然不可见）。反风险：拿「跨端要先加后减」当**永久半态**的挡箭牌。
- 📌 **违反时的判据**：
  1. 轮次 / 提交里出现「已收口到 X」而**无载体账**（"收口前 N"缺失）⇒ 声索，判未收口；
  2. 载体账 **M ≥ N** 却声称已收口 ⇒ 违规；
  3. `docs/判据登记表.md` 某行**载体数 N 变小**，而「跨板块副本」列**仍有落点** ⇒ 登记与实况不符（**就地改正**登记表）；
  4. 只改注释 / 只加转发层就当"销了副本" ⇒ 违规；
  5. 同一判据在不同时间被**反复收口** ⇒ 直接去查上一轮的载体账**有没有第 1 步**（没收完的征兆）。
  ⚠️ **诚实边界**：只有 ②（类型层定义点 ≥2）可机判；1、3、4、5 须人工核对（`ADR-0002` 第 6 级）。
