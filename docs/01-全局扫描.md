## 一、这是什么应用（先建立地图）

**一句话**：以**无限画布**为核心的 AI 创作工作台——用户在画布上摆节点（文案/素材/视频/生成），通过**多账号 webview 驱动豆包 / Dola / Lovart 等真实网站**生成图片与视频，产物自动落盘并回填画布。`[确证]`（启动页文案「豆包画布 / 无限画布 · 素材连线 · 智能创作」，`_Component47.jsx:56-104`）

**关键定位**：它**不是**自己调模型生成，而是**用浏览器自动化驱动别人家的网页**，另加一条**第三方 API 通道**（火山方舟/可灵/Vidu 等）并行。`[确证]`

### ⚠️ 术语纠偏：两条"画布"必须分清

| 概念 | 实质 | 证据 |
|---|---|---|
| **应用画布** | 本应用编辑区：zustand store `L` 持有 `nodes/edges/library`，用 **@xyflow/react** 渲染 | `shared.js:26752`、`_Component42.jsx:1444` |
| **外部站点页面** | 被 `<webview>` 打开的豆包对话页 / Lovart 画布页——`hp`/`wp`/`wP` 只是**抓图采集器** | `hp` `22663-23233`、`wp` `32493-32941` |

> 混淆点：`hp` 里的 `CANVAS/PANEL/FEED/SITE` 是**外部页面区域枚举**（给抓到的图打作用域标签），**不是**应用画布常量。`[确证]`（`22664-22669`）
