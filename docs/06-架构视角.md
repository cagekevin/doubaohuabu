## 视角 4 · 长任务生命周期 `[确证]`

**生成任务时间轴**：
```
提交 ──> [可选] 选号排队 ──> 组装报文 ──> 发送（Bu，maxRetries=1，sessionId 幂等）
   ──> 轮询（3s/次，静默 9s 判无真实图）──> 取图（Lc）──> 去重（sm）──> 写回节点
   ──> 终态：settled | no-real-image | timeout | already-finished | manual
```

| 能力 | 实现 |
|---|---|
| **进度上报** | `onStatus({phase,message})`（抓取）；`onProgress`（发送）；`onApiJobEvent`（API 任务） |
| **取消** | `cancelApiJob`(30694)；`user-cancel` 不重试（40411-40530） |
| **超时** | 页面 `hl`/`Vo`；轮询静默阈值 `ER`；API 轮询连续 5 次网络失败判失败 |
| **重启恢复** | ⚠️ **无真正断点续传**：`openProject` 时**清理** genvideo 的 `_pendingAttempt(s)` 与 queued/submitting/running 的 `apiJob`（29941-29958）——即**重启即放弃未完成任务** |

## 视角 5 · 失败降级链路 `[确证]`

```
发送失败
 ├─ 不可重试表 f3 → 停手 + 人工介入提示（含 safety-promise「防封号」）
 ├─ 换号表 p3     → 自动换号重试（quota / account-invalid / busy）
 ├─ 重试表 h3     → 稍后自动重试（rate-limit / page-timeout / page-error）
 └─ 兜底 unknown  → 标记「发送失败」

API 任务失败
 ├─ 401/403 auth、400/422 bad_request → 不重试
 ├─ 429 / 5xx / status 0 → 重试（退避 2s/8s/30s）
 └─ 主服务商 quota/auth 失败 且 配了不同 fallbackProviderId → 自动换兜底重开一次

站点抓取失败
 └─ 两通道降级：webview 多帧 → webview 单页
    （真实 Chrome CDP 通道在本版本为**死代码**，见 09-校验记录 C2）
    └─ canvas 渲染兜底 → 「导出画布快照」

站点选择器失效
 └─ 豆包发送按钮四级降级（Zl）；Dola 用服务端稳定 id 抗改版
```

## 视角 7 · 错误处理分层 `[确证]`

| 层 | 错误类型 | 处置 |
|---|---|---|
| **业务错误** | 额度不足 / 账号失效 / 文本框空 / 无可用账号 | 分类表 → 换号 or 停手 |
| **上游错误** | 风控拒绝 / 人机验证 / 安全确认 / 接口限流 | 分类表 → 停手（防封号）or 重试 |
| **系统错误** | 页面超时 / 页面异常 / 网络异常 | 重试；`backendErrors` 横幅（`copyright`/`quota`/`generation_failed`/`network`/`auth`） |
| **持久化错误** | 序列化失败 / 配额超限 | **放弃保存** + `setSaveError` |
| **壳层错误** | 子进程崩溃 | `child-process-gone` → 写 `dmDebugLogPath`（`main.js:625-632`） |

## 视角 8 · 并发模型（竞争点清单）`[确证]`

| 竞争点 | 机制 |
|---|---|
| 账号占用 | 内存态 `Er`(忙集合) + `Kc`(负载)，`markAccountBusy`（34477）；`Ei` 返回 `all-busy` |
| 抓取互斥 | 并发锁 `Xa` → `busy` / 「上一次抓取还没结束」（32531-32538） |
| 发送幂等 | `sessionId` 去重（防重复点菜单，40411-40530） |

| API 任务并发 | `_concurrency` 按 provider 限制 running 数，`pump()` 排队 |
| 持久化并发 | 防抖 600ms + `_persisting` 标志 |
