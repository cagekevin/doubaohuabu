## 三、提示词模板与继承树

### 3.1 组装层级（继承关系）

```
im({body, model, duration, ratio, stylePrefix, mediaType})        ← 通用层（35451-35485）
 ├─ image:  stylePrefix + body
 └─ video:  `视频生成 ${stylePrefix}${body}${paramsSuffix}`        ← paramsSuffix 由 rR(...) 生成
    │
    ├─ PL(...)  图片报文（40361-40410）
    │    `画一张：${body}，画面比例 ${ratio}，${生成 N 张|只生成一张}，使用 ${model} 模型，图片分辨率 ${1K|2K|4K}`
    ├─ TL(...)  视频报文（40318-40360）
    └─ $L(...)  账号节点报文（40236-40317）
         texts 经 In + Qc(refMap) 解析 → 换行合并；无文案 → `请参考以下 N 张素材图片进行创作。`
```

| # | 规则 | 证据 |

| 2 | **`@` 引用解析**：`@[<id>\|<label>]` → 「参考图N」，由 `Qc`(40117-40229) 处理，`In` 归一化 | |

| 4 | **空文案兜底**：`请参考以下 N 张素材图片进行创作。` | 40236-40317 |

## 七、失败分类规则（驱动调度）

> 完整 14 项见 `04-AI协议版.md` 附表。**规则要点**：

| 规则 | 说明 |
|---|---|
| **安全优先** | 命中 `safety-promise`（出现安全确认）→ **停止自动重试**，理由是**防封号**（41432） |
| **换号 vs 停手** | `quota`/`account-invalid`/`busy` → 换号；风控/人机验证/需人工确认 → **停手** |
| **重试边界** | 只有 `rate-limit`/`page-timeout`/`page-error` 可重试 |
| **正则驱动** | `account-invalid` = `/(账号已失效\|未登录\|登录已过期\|登录状态\|账号不可用\|掉线)/`；`quota` = `/(次数已用完\|额度.{0,6}(用完\|耗尽\|不足)\|…\|订阅会员\|会员.{0,4}权限\|配额)/` |
| **兜底** | 未命中任何表 → `unknown`（`retryable:true`, `switchAccount:false`） |
