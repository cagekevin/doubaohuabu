## 一、调用边界总览

| 边界 | 载体 | 冻结? |
|---|---|---|
| 渲染层 ↔ 主进程 | `window.api`（IPC） | **是** |
| 资源引用 | `img://` / `vid://` / `appasset://` | **是** |
| 持久化 | localStorage 16 键 + 磁盘布局 | **是** |
| 第三方服务 | provider adapter（`api/`） | 是（可加 provider，不改已有） |

> ★ **IPC 边界的失败形状**（`TD-13-14`，2026-10-11）：`main.js` 的 **67 个 `ipcMain.handle`** 里，
> **20 个包 `ipcGuard`**（把抛转成 `{ok:false, error:<原文>}`，原则 6）、**47 个函数体自带 `try/catch`**（与守卫**等价**，明确豁免）、
> **两者皆无 = 0** ⇒ 主进程异常**不会**以 rejected IPC 逃到渲染层。
> ⚠️ **新增 handler 的规矩**：**要么**自带 `try/catch`，**要么**包 `ipcGuard` —— **二者必居其一**。

## 三、自定义协议契约

| 协议 | 注册 | 实现要点 |
|---|---|---|
| **`img`** | 特权 `main.js:648`；handler `987-1012` | 按 sha1 前 16 位存 `imagesDir()/<hash>.<ext>`；`?w=N` 返回缩略图 + CORS 头；`resolveImageRef` 在 `imagesDir()/legacyImagesDir()/各项目 images` 查找，`name` 去分隔符防穿越（734-749） |
| **`vid`** | 特权 `651`；handler `1017-1059` | `saveVideoFromUrl` 按 URL sha1 命名，带豆包 UA/Referer，**<1024B 视为异常不落盘**（764-803）；handler **显式支持 Range/206**，`<video>` 可拖动进度条 |
| **`appasset`** | 特权（含 `bypassCSP`）`656`；handler `1060-1098` | 映射 `dist/`，按扩展名给 MIME（`.wasm→application/wasm`），**解析后强制仍在 dist 根内** |

三者均 `standard / secure / supportFetchAPI / stream / corsEnabled`（`647-657`）

> ⚠️ **`vid://` 前端应用区未使用**（只用 `img://`）——衔接点 `[待验证]`，重写视频节点前必须跑一次确认

| **本地激活补丁** | ★ **已删除（2026-10-11，`TD-13-4`）**：原 `LOCAL_MODE=true` 让 `checkLicenseStatus` **恒返 `ok`**、`activateWithCode` **任何码都成功**（跳过 Ed25519 签名 + 时间防篡改）⇒ **许可形同虚设**。**现已恢复验签**（删除时**无存量激活码**，零迁移成本）。⚠️ `SALT`/`HMAC_SECRET` 明文属**客户端固有限制**（桌面端密钥必然可提取），已如实登记，不在本债范围 |
| 稳定 ID | `collectStableId()`：主键=硬件序列号（macOS `IOPlatformSerialNumber` / Win `wmic bios serialnumber` / Linux `machine-id`）；辅键=硬件 UUID；兜底=CPU 型号+内存；**明确排除** hostname/MAC/IP（100-177） |
| 生成 | `sha256(SALT + '::' + primary\|\|secondary\|\|fallback)` 前 16 位 → `DBPC-XXXX-XXXX-XXXX-XXXX`；锚定 `userData/machine_id.dat`（原子写），主键未变则沿用旧码（189-302） |

### 7.2 激活与防篡改

| 机制 | 实现 |
|---|---|
| 激活码 | `base64url(JSON{mc,exp,v}) + '.' + base64url(ed25519 签名)`；验签 → 机器码绑定 `payload.mc === 当前机器码` → 版本 → `exp` 为数字。**私钥不进客户端**（307-351） |
| 许可文件 | `userData/license.dat` = `{v,mc,code,exp,activatedAt,sig}`，`sig = HMAC_SHA256(HMAC_SECRET, 去 sig 的 JSON)`；读时校验 HMAC，篡改 → `{tampered:true}`（461-502） |
| 一次性激活码 | `used_codes.dat`（**AES-256-GCM**，密钥由 `HMAC_SECRET` 派生；解密失败 = **fail-close 拒绝激活**）；`codeHash` 记录已消耗（504-571, 674-712） |
| 时间防篡改 | 可信时间源 `fetchTrustedTimeMs`（读 HTTPS `Date` 头，`TRUSTED_TIME_HOSTS` = 百度/qq/apple/doubao）；单调时钟锚点 `process.hrtime`；持久化基线 `timeanchor.dat`（HMAC）；`detectTimeTamper` 检测回拨 → `status:'tampered'`（16-23, 51-56, 392-409, 578-597） |
| 状态 | `checkLicenseStatus` → `status ∈ {ok, none, invalid, expired, tampered}`（602-650） |

## 九、边界表：哪些能改、哪些不能

| 层 | 能否改 | 说明 |
|---|---|---|
| `electron/**` | **不能** | 冻结；改动即「改后端」 |
| `window.api` 方法/channel/形状 | **不能** | 同上 |
| localStorage 键名与格式 | **不能** | 老数据兼容 |
| 磁盘布局 / 快照格式 / `img://` | **不能** | 同上 |
| provider adapter | **可加** | 新增 provider 不改已有 |
| 渲染层内部（组件/状态/样式） | **可改** | 重写范围 |
