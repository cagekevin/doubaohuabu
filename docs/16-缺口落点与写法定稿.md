## §0 三条铁律 + 落点判定表（照此裁决，不再自由发挥）

**三条铁律**（技能 08 §二）：① 内核不得 import 适配器/状态/视图；② **视图不得直接调宿主 API**；③ 冻结层不得 import 上层。

**落点判定表**（技能 08 §八，命中即停）：

| 你手上的东西… | 放哪 |
|---|---|
| 纯计算 / 转换 / 校验（无副作用） | `core/rules/` |
| 编排（串端口，不碰 React / 不碰 `window`） | `core/usecases/` |
| 端口类型（只有类型，零实现） | `core/ports/` |
| 数据结构 / 判别联合 / 默认值 | `core/model/` |
| 接触 `window` / `fs` / 网络 / `localStorage` / **`<webview>` 命令** | `adapters/` |
| 易变的第三方站点逻辑 | `adapters/site/<站点>/` |
| 发版即冻结的键 / 格式 / 协议 / 迁移 | `stable/` |
| 全局状态（跨子树） | `state/slices/`（按**共享范围**切） |
| 只在某子树内 / 弹窗开合 / 输入中态 | 子树 slice 或 **`useState`** |
| 能算出来 | **渲染时算，不入 state** |
| React 视图 | `ui/` |
| 文案 / 常量 / token / 键 | `constants/` · `styles/tokens.css` · `stable/contracts/keys.ts` |
| 选实现 + 接线 | `bootstrap/` |

## §4 ★ 不新增闸：用**结构收口**替代（用户裁定 2026-10-10）

> **裁定**：**能不要闸就不要** —— 闸有维护成本，不想维护。
> **依据（技能自带的成本律）**：`debt.mjs` 头注 / `arch-index.mjs` 的定性 ——「**闸的成本守恒律：合法通过成本 > 绕行成本 ⇒ 必被绕**」「写文档要的是**规范**，不是门禁」。
> **★ 细化判据 F3（本次新增，替代原拟 6 条闸）**：想加一条检查时，**先问「结构上能不能让它无法违反」**：
> - **能** ⇒ **不建闸**：收口结构，让错的写法**编译不过 / 无处可写**；
> - **不能且违反代价高** ⇒ 才考虑建闸，**且只建零维护的**（折进已有命令、不新增规则）。
> **一句话**：**很多"闸"其实是"结构收口没做干净"的补丁 —— 收口做完，闸就该退役。**

### §4.1 逐条替代（原拟 6 条闸 → **全部**改为收口）

| 原拟闸 | 防什么 | ★ 免闸替代（结构收口） | 为什么结构就够 |
