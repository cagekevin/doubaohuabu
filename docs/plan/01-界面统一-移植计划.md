## §1 真源原则

**两层真源，各管一段；实现单向对齐。**

| 管什么 | 真源 | 方向 |
|---|---|---|
| 行为 / 位置 / 文案 / 字段 / 分支 | 原版代码 `docs/豆包画布原版参考/expanded_components/` | `src` 照抄 |
| **视觉 / 形态 / 结构 / 命名 / token 值** | **`docs/mockup/`** | **`src` 向它对齐** |
| 实现 | `src/` | 只消费，不反向定义 |

四条推论（同一条原则的必然结果）：

1. **一个东西只有一个类。** mockup 已统一的族照搬进 `src`，**结构与命名一起搬**（适配 CSS Modules：`panelHead` + `composes`）。
2. **一个值只有一处定义。** 同名 token：mockup 为准。`src` 独有的 token：**回填 mockup**。
3. **出处只指向真源。** 引用原版 `文件:行`（行为）或 mockup 的**选择器名**（视觉）；**不引用行号**。
4. **判据不得自相矛盾。** `docs/17` 同节不许并存两套相反裁定。

## §7 已决议（2026-10-12 用户裁定，含原版源码取证）

> 口径：**参考原版的骨架与位置；结构、颜色、尺寸我们**自己**定**（不以"原版就这样"或"mockup 就这样"为挡箭牌，找**最正确**的值）。

| # | 决议 | 依据 |
|---|---|---|
| 1 | `--color-action-primary` `500` → `600` | 浅色主按钮变深一档，对比度 4.47→6.27（`docs/17 §8.3`） |
| 2 | `--color-success` / `--color-danger` `500` → `700` / `600` | 反馈实心底变深，白字达标（`docs/17 §8.3`） |
| 3 | 关闭钮 28×28 → **`panelClose` 24×24** | 24 = `--dim-5`，标准点击目标；统一全族一个规格 |
| 4 | 药丸实心 → **软底彩字**（`.pill`）；实心底归 `.badge` | §2.4 分工：药丸高频不刺眼、徽章强提示 |
| 5 | **`.node` 溢出 = `overflow: hidden` + `overflowVisible` 开关**（src 现状） | **最正确**：ReactFlow 用 `transform` 定位 ⇒ `overflow` 连 fixed 子元素一起裁，圆角裁剪与框外浮层**在节点 DOM 内不可兼得**。`hidden` 让圆角自动裁、通栏媒体天然裁好；浮层节点显式开 `overflowVisible`。mockup 的 `visible`+逐块补圆角是**演示态**（浮层画在节点内），非设计真值 ⇒ mockup 侧回改 |
| 6 | **8 项观感差异：全部 mockup 为准**（§1 推论 2） | 见 §7.1 |
| 7 | **`GroupNode` 统一用 `NodeShell`** | **"独立"没有意义**：原版 `GL.jsx` 的头（`icon + name + count + 取消组`）与其他节点**同构**；真差异只有三条且都能用 props 表达 —— `handles={false}`（原版 GL **没有** `_Component30`）· 头用 icon 而非 dot · `padded={false}`（body 是子节点容器）。`NodeShell.tsx` 里「组节点不用本外壳」注释**是错的，删** |
| 8 | **`MaterialNode` / `DownloadNode` / `VideoNode` 缺 handle = 功能缺陷，补** | **原版源码取证**（`expanded_components/`）：`_Component30` = 连接点（`<Handle type="target|source" position={Left|Right}>`，与我们 `NodeHandles.tsx` 逐字对应）。<br>· 素材 `fL.jsx` → `<_Component30/>`（target + source）<br>· 下载 `WL.jsx` → `<_Component30 source={false}/>`（**仅 target**）<br>· 视频 `BL.jsx` → `<_Component30/>`（target + source）<br>⇒ 三者都该有 handle，我们 src 全漏了 |

### §7.1 · 8 项观感差异的逐条决议（★ 全部 mockup 为准）

> **依据 = §1 推论 2**：同名 token，值以 mockup 为准，改 `src`。
> 这 8 项都是「同名不同值」，且 mockup 的值**逐字对源**（如 `--handle-size: 14px` =
> 原版 `.react-flow__handle` 14×14，`mockup.css:460` 注释）——**不是演示放大**。

| `--edge-stroke-width` | `1` | **1** |
| `--edge-stroke` | `--color-text-faint`（灰） | **灰** |

判据：**名字说明形态**（`docs/17 §1.3`）。形态不同 ⇒ 不同族，**不硬并**。

| # | 情形 | **裁决** | 理由 |

| 1 | `SelectionToolbar.menuHead`（菜单头） | `.panelHead` + **`.isCompact`** | 它就是「紧凑面板」的头 —— 同一个东西的紧凑态，不是新物种 |

### 10.3 执行纪律

#### 纪律 1 · 顺序不可换
- `mask` ↔ `overlay` **名字互换**必须按 §5 刀 4 的 6 步顺序（颠倒会撞名）

#### 纪律 2 · 每刀必验，且「0 命中」当可疑
- 每刀跑 `npx vite build`（`composes` 的唯一机器闸）+ §6 的处数复算
- **`0 命中` 必须当可疑**：本仓实录 —— 搜索工具对 `flex` / `padding` 这类常见词会**假返回 0**
- 计数口径按 P6：数**独立类名** · **排除注释行** · 必须**打印命中数**

#### 纪律 3 · 遇到本计划没写到的 → 停下改本计划
**不许就地决定**（就地决定 = 又造一个"第二个物种"，正是本轮要消灭的东西）。

#### 纪律 4 · 碰到「功能还没做完」→ **空着 + 当场登记债务**（不自己造）

**背景**：本仓约 **25% 的功能未完成**（用户 2026-10-12 口径）。移植时会碰到「原版有这个按钮 / 这个态，但我们这边功能还没落」。

**处置**（三步，缺一不可）：

1. **留空** —— 骨架 / 类名 / 位置**按统一规范落好**，内容留占位或省略
2. **当场登记债务** —— 唯一入口（**禁手写 `债务.md`**，它是脚本产物）：
   ```bash
   node scripts/debt.mjs add --area <NN> --summary "…" --class 增债 --rate 中 --owner 结构债 --anchor <区域日志文件名>
   ```
   | 注意 | 说明 |
   |---|---|
   | `--anchor` | 必须是 `daily/架构日志/` 下的**区域日志文件名**（`<NN>-…-<日期>.md`）——**不能带路径分隔符**（带了会被 `anchorProblem()` 拒写） |
   | 引号 | ⚠️ **摘要 / note 里不要用 ASCII 双引号 `"`** —— PowerShell 会把它当引号边界，**参数被截断**；用中文引号 `「」` |
   | 查重 | 登记前先 `node scripts/debt.mjs search <关键词>`（跨主表 + 归档） |
   | 区域号 | 先 `node scripts/debt.mjs list` / `mothers` 确认 `--area` 用哪个号 |
3. **不许**「顺手把它实现掉」—— 那是另一条链路（`ui` 只调 state action；行为在 `core/rules` / `usecases`），**超出本计划范围**（§9 约束 4）

> ⚠️ 债务登记是**执行期动作**，不是开工前的任务 —— 没碰到未完成功能就不该有新增债务。
