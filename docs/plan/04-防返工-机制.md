# 04 · 防返工机制（Plan）

> **一句话**：**返工不是"做错了"，是"做完之后还必须再做一遍"**。
> 本文件只列**会产生二次返工的四类根因**，每类给一条**机制**（不是嘱咐、不是清单、不复述判据）。
> 效力：判据本体 = `docs/11`；写法 = `docs/16`；缺口真源 = `docs/13/14/15`。本文件只写"**怎么不再重做**"。

## 1 堵 R1 · 证据分级（唯一能防"注释杀人"的机制）

- **规则**：结论只能引用 **A 级证据** —— ① **源代码**（`docs/豆包画布原版参考/`）② **命令输出** ③ **编译期结构**（类型 / 穷尽断言 / 结构穷尽）。
  **B 级**（注释 · `docs/13-16` · 债务 · ADR · **本文件**）只能用来**提出假设**，**不能下结论**。
- **写法（这一条能省掉每轮的"改对登记"）**：**禁行号引用**，改引**符号名**。
  ❌ `pollResults:239-240` · ❌ `docs/13:214` · ❌ `_Component43:1543`
  ✅ `pollResults` · ✅ `buildAccountNodePayload` · ✅ `Be 的 Phase 3a`
  （行号一改就失真 ⇒ 逼出"每轮都在改对登记"的返工 —— 本会话已发生 **5 次**。）
- **落地**：每片 `docs/16` 条目**加一栏 `证据等级`**（`A：<源符号> + <命令>` / `B：仅注释`）。**B 级结论不许进 `src/`。**
- **违反的样子**（本会话原话，留作反面样本）：「`core/rules/dedupe.ts` 有显式裁定『本仓暂无落点』—— 不动。」

## 2 堵 R2 · 把"纸面"变"真"（最小代价）

- **交付定义加一条**：**改了 `src/` ⇒ 必须 `npx vite build` + 至少跑一个 `scripts/verify-*.cjs`**（`verify-e2e` 起）。
  跑不动 / 跑不了 ⇒ **必须写"未验" + 手测清单**（前提 → 操作 → 期望 → **实际留空**）。
- **机制**：`scripts/gates.manifest.json` 挂两道 —— `build`（`npx vite build`）· `e2e`（`node scripts/verify-e2e.cjs`）。
  代价：`npm run check` 变慢；**收益：没有它，所有 UI / 接线改动都是纸面**。
- **判据**：条目里**写"未验"不算问题**；**既不写"未验"也不写"已验" = 不合格**（假装验过 = 返工之源）。

## 3 堵 R3 · 不留半态（B5 + 片自洽 + 半径外对账）

- **规则**：
  ① 一个符号落下的**同一批**必须有**生产消费者**，否则**先别落**（判据 B5）；
  ② **每片自洽**："删+做"同批完成，不留"以防万一"；
  ③ **关闭的闸必须在结论里点名** —— 不许写「5 道全绿」了事（现况：**5 开 / 1 关，关的是 `dead-code`**）。
- **半径外对账**（ADR-0003 §⑥ 后置对账）：改完问一句「这次改动让**谁**失去了消费者」—— 本次 diff **之外**的零引用符号**逐条处置**（真死删 / 接上 / 是能力留痕）。
- **立刻要收的三笔**（★ **2026-10-13 已收**）：`fetchWatermarkFreeByThread`（源侧 0 调用 ⇒ 定性不做 ⇒ **删 usecase**，端口 / adapter / 页内脚本留作"已移植能力"）· `lib/url` 的 `shouldDiscardImage` + `fileNameFromUrl`（幽灵预留 ⇒ **删**）· `node.selfCheckDefaults` + `NODE_TYPES` + `schemas` 两常量（仅测试 / 前端 0 消费 ⇒ **删**）。级联与半径外对账见 `docs/16`。

## 4 堵 R4 · 一份真相（**用类型，不用闸**）

> 手段优先级：**真源 = `ADR-0002`**（删 ＞ 类型层 ＞ 唯一入口 ＞ 目录 ＞ 检查＋负例探针 ＞ 诚实声明）—— 本行不再自列一份。
> 本节**已删掉"挂闸"的做法**（闸是最低两档且会漂）⇒ 真源 = `docs/11` §六·六。

| 目标 | 结构机制（`docs/11` §六·六） |
|---|---|
| 「同名两义」类型 | **M1 品牌类型 + 唯一构造器**：名字不再承载语义（`WirePayload` / `SiteSendPayload` 手写不出来）⇒ 「同名」这件事**失去意义** |
| 第二份可变状态 | **M3 唯一所有者 + 私有构造**：`ui` 拿到的只是只读视图 ⇒ 自己攒不出第二份 |
| 模块级第二份表 | **M6 注册表不导出**：端口返回方法对象，表本身无导出 |
| 「落了没人调」 | **M5 投影即"有生产者才有字段"**：没生产者 ⇒ UI 写不出来 |
| 键名 / 值形状只有一份 | 既有结构穷尽（`keys.ts` · `lsValues.ts` · `schemas.ts`）—— 已覆盖 |
| **CSS 变量「用了没定义」** | ⚠️ **没有结构解**（纯 CSS 不吃类型）⇒ 只能**当场跑**（`css.mjs check` 的 `vars` 段），归 §2 的"当场验"清单，**不假装能结构消灭** |

## 7 一句话

**防返工 = ① 只认源代码与命令输出当证据（禁行号引用，改引符号）② 改了 `src` 就 build + 冒烟，验不了就写"未验" + 手测清单 ③ 不留"落了没人调"的半态，关闭的闸必须点名 ④ 同一真相只留一份，并把能机检的三种（同名类型 / CSS missing / 死代码）用脚本钉死。**
