## 单元 1 · 文生图生成（网页通道）

**入口**：`PL`(40361) 组装 → `Bu`(40411) 发送 → `DR`(36335) 轮询 → `Lc`(23838) 取图

```jsonc
// INPUT
{
  "account": { "id": "acc_x", "type": "doubao", "partition": "persist:acc_x" },
  "text": "一只猫",                       // 用户正文（可能含 @[id|label] 引用）
  "stylePrefix": "国风二次元插画风格，工笔线条，青绿山水配色，",
  "ratio": "1:1",
  "count": 1,
  "model": "Seedream 5.0 Pro",
  "resolution": "2K",                     // '1K' | '2K' | '4K'
  "images": ["img://a1b2...png"],         // 参考图（已外置的引用）
  "sourceNodeId": "ig_xxx"
}

// OUTPUT（成功）
{
  "ok": true,
  "sessionId": "sess_...",                // 幂等键：同 sessionId 不重复点菜单
  "results": [
    { "dataUrl": "img://...", "source": "doubao", "accountName": "豆包01",
      "genKey": "gk_...", "ts": 1760000000000, "ratio": "1:1",
      "prompt": "国风二次元…（≤80字）", "params": { } }
  ],
  "endReason": "settled"                  // settled | no-real-image | timeout | already-finished | manual
}

// ERROR
{
  "ok": false,
  "reason": "retry-exhausted",            // 见下表
  "note": "多次重试仍失败",
  "failKind": "quota",                    // SendFailKind
  "label": "该账号额度不足，自动换号重试",
  "retryable": false,
  "switchAccount": true
}
```

**错误分支（必须全实现）**：

| reason / failKind | retryable | switchAccount | 触发条件 |
|---|---|---|---|
| `empty-text` | ✗ | ✗ | 文本框内容为空 |
| `no-account` | ✗ | ✗ | 无可用账号 |
| `account-invalid` | ✗ | **✓** | `/(账号已失效\|未登录\|登录已过期\|登录状态\|账号不可用\|掉线)/` |
| `quota` | ✗ | **✓** | `/(次数已用完\|额度.{0,6}(用完\|耗尽\|不足)\|…\|配额)/` |
| `busy` | ✗ | **✓** | 发送通道忙碌 |
| `risk-refuse` | ✗ | ✗ | 平台拒绝（风控/内容规范） |
| `safety-promise` | ✗ | ✗ | 出现安全确认（**防封号，停止自动重试**） |
| `human-verification` | ✗ | ✗ | 需人机验证 |
| `confirm-required` | ✗ | ✗ | 豆包需人工确认 |
| `send-stuck` | ✗ | ✗ | 发送卡住 |
| `rate-limit` | **✓** | ✗ | 接口限流 |
| `page-timeout` | **✓** | ✗ | 页面超时 |
| `page-error` | **✓** | ✗ | 页面异常 |
| `unknown` | ✓ | ✗ | 兜底「发送失败」 |

## 单元 4 · API 通道任务（第三方 provider）

**入口**：`submitApiJob`(30662) → 主进程 `job-manager` → `onApiJobEvent` → `applyApiJobEvent`(30708)

```jsonc
// INPUT
{ "providerId": "kling", "kind": "video", "params": { "prompt": "...", "duration": 5 },
  "sourceNodeId": "gv_xxx" }

// OUTPUT（渲染层收到的任务快照）
{ "id": "apj-<base36>-<seq>", "status": "queued", "kind": "video", "providerId": "kling" }

// 状态机
queued → submitting → running → downloading → done
                              ↘ failed / cancelled
```

**重试矩阵**（`job-manager.js:23-30, 171-182`）：

| HTTP | kind | 重试 |
|---|---|---|
| 401 / 403 | `auth` | ✗ |
| 400 / 422 | `bad_request` | ✗ |
| 429 | `rate_limit` | ✓ 退避 `[2s, 8s, 30s]` |
| 5xx | `server` | ✓ 同上 |
| status 0 | `network` | ✓ 同上 |

**兜底**：主服务商 `quota`/`auth` 失败且配了不同 `fallbackProviderId` → 自动换兜底**重开一次**（`job._usedFallback=true`）
**轮询**：网络失败连续 **5 次**判失败

## 附：错误分类总表（`_S` 41509-41525）

> **决策链路（`09-校验记录.md` C5 补录）**：
> ```js
> function _S(e) { ... for (const n of m3) { if (n.re.test(t)) return {kind,retryable,switchAccount,label} } return z0; }
> function g3({ note, attempt, maxRetry = 2 }) {
>   const r = _S(note);
>   if (!r.retryable || attempt >= maxRetry) return { action: 'give-up', label: r.label };
>   else if (r.switchAccount)                 return { action: 'retry-switch', label: r.label };
>   else                                      return { action: 'retry', ... };
> }
> ```
> - 三张表 `f3` / `p3` / `h3` 合并为 **`m3`**，由 `_S` **顺序遍历**（命中即停）
> - 兜底对象 = **`z0`**
> - **真正的决策点是 `g3`**：输出 `action ∈ {give-up, retry-switch, retry}`，**`maxRetry = 2`**（不是 1）
>
> ⚠️ 上表「14 项」是 `_S` 的失败分类；**另有独立的「回复类型分类器」**（`VR` 行 36626，kind = `none`/`offer`/`busy`/`other`/`no-reply`）——两者不可混（见 `09-校验记录.md` C4）

| 表 | kind | retryable | switchAccount | label |
|---|---|---|---|---|
| 不可重试 `f3`(41421-41463) | `risk-refuse` | false | false | 平台拒绝（风控/内容规范） |
| | `safety-promise` | false | false | 出现安全确认，已停止自动重试（防封号） |
| | `human-verification` | false | false | 需要人机验证，请到该账号页面手动处理后重跑 |
| | `confirm-required` | false | false | 豆包需人工确认，请到文本框查看回复 |
| | `send-stuck` | false | false | 发送卡住，请手动检查该账号页面 |
| | `empty-text` | false | false | 文本框内容为空 |
| | `no-account` | false | false | 无可用账号 |
| 换号/重试 `p3`(41464-41496) | `quota` | **true** | **true** | 该账号额度不足，自动换号重试 |
| | `account-invalid` | **true** | **true** | 账号已失效，自动换号重试 |
| | `busy` | **true** | **false** | 发送通道忙碌，稍后自动重试 |
| 重试 `h3`(41497-41501) | `rate-limit` | true | false | 接口限流，稍后自动重试 |
| | `page-timeout` | true | false | 页面超时，自动重试 |
| | `page-error` | true | false | 页面异常，自动重试 |
| 兜底 `z0`(41503-41508) | `unknown` | true | false | 发送失败 |

> ⚠️ **2026-10-10 修正**：`p3` 的 `retryable` 实为 **`true`**（原表误记 `false`），`busy.switchAccount` 实为 **`false`**（原表误记 `true`）。
